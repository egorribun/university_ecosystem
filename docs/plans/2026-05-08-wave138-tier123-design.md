## Phase 1 Explore findings (the 3 agents)

### SW investigation hypothesis paths (Agent 1)

Top hypothesis: **Path (a) CSP-nonce + strict-dynamic interaction**.

- `app/core/policies/csp.py:39` defines prod CSP:
  `script-src 'self' 'nonce-{nonce}' 'strict-dynamic'`
- Service Workers register from a separate-script context where
  `strict-dynamic` rules **don't** apply to external resource fetches
- W137 polish-v1 added nonce placeholders to inline `<script>` tags but
  the `/sw.js` fetch must navigate full CSP
- Likely fix: add explicit `worker-src 'self'` directive (W3C spec —
  Service Workers need their own CSP directive)

  workbox into single `dist/client/sw.js` (53,181 B verified)

  Chrome; W138 SW2 Phase A reproduces in real Chrome to disprove
