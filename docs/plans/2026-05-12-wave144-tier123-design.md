**Path A2 RECOMMENDED (npm-bundled + page.evaluate(source-string))**:
- `axe-core` already in `frontend/node_modules/axe-core/axe.min.js` (via `@axe-core/playwright` peer dep)
- Pattern:
  ```js
  const axeSourcePath = require.resolve("axe-core/axe.min.js");
  const axeSource = await fs.readFile(axeSourcePath, "utf-8");
  await page.evaluate((src) => { eval(src); }, axeSource);
  const results = await page.evaluate((opts) => window.axe.run(document, opts), runOptions);
  ```
- No `<script>` tag at all → CSP-agnostic by design
- ~15 LoC delta in [wave138-visual-audit.mjs:299-368](../../frontend/scripts/wave138-visual-audit.mjs:299)

**Mandatory pre-fix diagnostic step (~3 LoC)**:
