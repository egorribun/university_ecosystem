# Retained historical project license texts

`LICENSE-MIT` is the earlier root notice, retained verbatim. `LICENSE-ISC`
supplies the full ISC text corresponding to the pre-transition frontend
metadata. `LICENSE-APACHE` supplies the standard Apache-2.0 text corresponding
to the native crate's earlier `MIT OR Apache-2.0` metadata. The native wheel
also retains that Apache text as `LICENSE-APACHE-LEGACY`.

These texts document the existing grants for the material previously published
under them. They do not apply those grants to new Restricted Material. See the
[transition record](../README.md) for publication boundaries, source snapshots
and the distinction between previously licensed and new original portions.
