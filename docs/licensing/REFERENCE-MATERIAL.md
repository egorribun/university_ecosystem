# Bundled agent reference material

The 154 directories under `.agents/skills/` are reference tooling, not an
assertion of original product authorship. Docker excludes `.agents/`, but
public Git and source archives still distribute these files.

The original import was located in repository history. All 415 tracked skill
files were compared with the latest snapshot of
[Antigravity Awesome Skills](https://github.com/sickn33/antigravity-awesome-skills)
preceding that import (2026-07-22). The precise upstream commit, file paths and
per-file comparisons are retained in
[the source comparison](inventories/reference-skills.json).

326 files match byte for byte and 15 differ only in line endings. Another 12
match at the original import but have subsequent local changes. The remaining
62 differ or are absent at that candidate upstream snapshot. A match documents
a source relationship; it does not certify the upstream collector's ownership
of every contribution or of documents copied into its collection.

The collection's previously omitted
[MIT notice](reference-material/Antigravity-MIT.txt) is retained verbatim for
its applicable material. Existing Apache-2.0 notices within `algorithmic-art`,
`frontend-design` and `webapp-testing` remain in place and take precedence for
their material. Copied examples, third-party documentation and nested material
keep their own rights; an aggregate MIT notice cannot replace them.

**Remaining review:** identify the original upstream version and applicable
